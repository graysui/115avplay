# MediaVault 功能规格

本文件定义做什么和验收；[主设计](../../docs/PROJECT_SPEC_GO_VIRTUAL_MEDIA_SERVER.md)定义技术规则，[计划](./plan.md)组织实施，[追踪表](./traceability.md)连接需求与任务。当前为设计阶段，任务完成状态不因文档修订自动变为已实现。

## 1. 产品目标与范围

单机 Go 服务从 SQLite 投影虚拟影片库；通过 Emby 协议供客户端浏览、搜索、选择版本、续播，通过 115 就绪文件的短时 302 直连播放。全量/30D 数据、JavDB 刮削与榜单补充目录，任务和临时资产可恢复、可追踪。

首版兼容目标为明确版本的 Infuse 和 VidHub，须通过 G0/阶段验收；其他客户端尚不承诺。仅 DirectPlay，不转码或重封装，不处理 ISO/VOB/蓝光原盘/分段拼接，不生成 STRM，不实现多租户、多网盘、拼音搜索。

已有资源优先；冷资源可在后台预准备，播放同步等待上限默认 8 秒，超时返回“准备中”错误状态，客户端可能显示通用错误，准备完成后由用户手动重试。首版不使用占位短片，不承诺客户端自动重试或所有网络下秒开。

## 2. 用户故事

| ID | 故事 |
|---|---|
| US-1 | 在六个可重叠视图浏览影片，全局按影片去重 |
| US-2 | 精确番号本地未命中时触发在线补全；普通关键词只查本地 |
| US-3 | 就绪文件直接播放；冷资源可预准备并在完成后手动重试 |
| US-4 | 选择中字/4K 等具体版本，同影片不同版本的并发请求不串流 |
| US-5 | 每用户收藏、已看、继续观看；不同设备共享进度 |
| US-6 | 手动/定时导入全量和 30D，抓取日周月榜与 TOP250 |
| US-7 | 按日期字段/范围批量刮削、包含失败或显式覆盖免刮削策略，查看持久进度 |
| US-8 | 管理授权、用户、视图、任务并发、代理、临时目录和保留时间 |
| US-9 | 看到外部依赖故障、同步缺口和清理隔离告警 |
| US-10 | 重启后接管任务，安全清理本服务拥有的临时文件 |

## 3. 功能需求

优先级“必须”指首版验收范围；仅文档中的扩展客户端为后续目标。所有以下 FR 均为必须。

| ID | 需求 | 验收规则 |
|---|---|---|
| FR-DATA-1 | SQLite WAL 为本地业务权威，目标表/约束以 DDL 为准 | 空库建库、结构校验 |
| FR-DATA-2 | 既有库受控重建迁移、保留数据与状态转换 | 备份、故障回滚、主键/字段对比；新旧库语义一致 |
| FR-DATA-3 | 同影片最多一条 preferred 缓存 | 部分唯一索引；请求时重新选源 |
| FR-DATA-4 | 类型化资源身份：btih/ed2k/existing | 等价链接同 key；跨影片冲突留记录 |
| FR-INGEST-1 | GitHub 全量/30D 下载、GCM 认证解密、CSV 入库 | 校验清单/文件/表头，不把认证失败当空包 |
| FR-INGEST-2 | 全入口过滤 VR/欧美/写真，FC2/国产默认免刮削 | 统一样例表和独立策略字段 |
| FR-INGEST-3 | 去重同时允许受控字段更新，保留人工锁与来源 | 同 hash 修正不破坏云绑定/用户数据 |
| FR-INGEST-4 | 04:00 定时与手动互斥；覆盖缺口全量追补 | 分包失败不推进水位；重启可重放 |
| FR-SCRAPE-1 | 自动处理完整度 0/3 且策略 auto 的到期记录 | 回填字段，不覆盖人工锁 |
| FR-SCRAPE-2 | 部分成功有补全间隔和预算 | 每日一次，5 次缺字段后暂停，可手动恢复 |
| FR-SCRAPE-3 | 明确无结果和暂时故障分开处理 | 三个不同日无结果且发现超过十天才暂停；风控不永久放弃影片 |
| FR-SCRAPE-4 | Tier/可播分组后按中字>破解>4K>有码>体积选默认版本 | 无唯一候选超高分；否定词与同分规则确定 |
| FR-SCRAPE-5 | 日周月榜/TOP250 手动与定时核对，包括已收录缺资源影片 | 分页/新增资源/定时规则验收 |
| FR-SCRAPE-6 | 所有 JavDB 调用共享限流、代理、熔断与预算 | 模拟 429/403 无请求风暴 |
| FR-STREAM-1 | 全量/增量扫描 115 永久库，完整快照对账 | 多层/根部视频、分页失败不淘汰 |
| FR-STREAM-2 | 指定可转存版本进入持久任务 | 远端结果未知先对账，就绪资产有归属 |
| FR-STREAM-3 | 按错误类别回退 | 暂时错误保留文件身份；失效永久库可回退其他类型 |
| FR-STREAM-4 | 等待上限、503 preparing、后台预准备及手动重试 | 冷请求不记播放进度，不返回假正片 |
| FR-STREAM-5 | TTL 清理仅限本服务拥有的临时资产 | 活跃租约保护、异步确认、删除/重启不丢身份 |
| FR-STREAM-6 | 同绑定同版本转存合并 | 不同版本独立；数据库活动任务唯一 |
| FR-EMBY-1 | 握手、认证、views、PlaybackInfo 与客户端能力适配 | 固定两客户端版本通过完整链路 |
| FR-EMBY-2 | 视图、列表、分页、排序和本地检索 | ID稳定，SortOrder有效，列表去重 |
| FR-EMBY-3 | 详情/PlaybackInfo 多版本与真实媒体字段 | 显式版本不静默替换；未知字段不伪造 |
| FR-EMBY-4 | 图片代理/缓存/占位图 | ETag、容量与错误回退 |
| FR-EMBY-5 | 就绪媒体 302，支持经过验证的 HEAD/Range 行为 | 无转码/重封装能力声明 |
| FR-EMBY-6 | 进度、收藏、已看、继续观看 | 完播幂等、用户隔离、会话冲突策略 |
| FR-EMBY-7 | 精确番号在线补全有界降级 | 6 秒含排队，失败200空列表并至多一个后台补充尝试 |
| FR-ADMIN-1 | 统计完整度与策略分别分布 | 各组互斥，pending按可调度定义 |
| FR-ADMIN-2 | 影片/版本查看与手工修正、安全删除 | 人工锁、资源身份不可原地改写、删除保留清理记录 |
| FR-ADMIN-3 | 指定日期字段和范围、包含失败、进度 | NULL日期规则明确，exempt须独立选项 |
| FR-ADMIN-4 | 榜单/增量/全量/预准备触发及日程配置 | 202 job_id，重复返回已有活动任务 |
| FR-ADMIN-5 | 管理员实时日志与任务通知 | WS鉴权；断连后可查DB任务 |
| FR-ADMIN-6 | 系统配置、115授权、用户、固定视图管理 | secret保持/替换/清除；热修改不篡改既有任务快照 |
| FR-ADMIN-7 | 管理员与普通用户权限分离 | audience/用户归属/enabled/到期检查 |
| FR-OPS-1 | healthz/readyz和依赖详情分离 | 空库/115失效仍可管理，DB故障503 |
| FR-OPS-2 | 持久告警、横幅、Webhook去重和恢复 | 默认静默1h，投递不阻塞业务 |
| FR-OPS-3 | 日志/图片/下载/任务保留与容量 | 未完成清理记录不得因裁剪丢失 |
| FR-OPS-4 | 所有长任务租约、重试、参数快照与恢复 | 重启不无限卡住或盲目重复外部提交 |

## 4. 非功能需求

| ID | 要求 |
|---|---|
| NFR-1 | Go单二进制嵌入前端；Linux amd64/arm64；镜像目标<50MiB（未压缩层，不含运行数据） |
| NFR-2 | 指定基准机/数据规模下，空闲RSS<=80MiB、普通峰值<=256MiB、全量<=512MiB；列表/搜索分位目标见主设计§12 |
| NFR-3 | 就绪播放本地Resolver P95<=100ms，115网络与客户端起播另测，不作无条件秒播承诺 |
| NFR-4 | JavDB共享低并发和限流预算，在线查询超时包含排队 |
| NFR-5 | 外部调用超时/代理可配，错误分类、有界队列、进程可恢复 |
| NFR-6 | 迁移不丢业务数据，事务可回滚，旧版本程序拒绝写新库，备份恢复演练通过 |
| NFR-7 | 独立主密钥加密secret，鉴权票据仅存hash，日志/fixture脱敏 |

## 5. 端到端验收

| ID | 场景与期望 |
|---|---|
| AC-1 | 空库启动、管理员初始化与密钥正确，readyz200；未授权/未同步不会阻塞管理 |
| AC-2 | 30D导入、过滤、等价资源去重、字段更新和FC2策略正确 |
| AC-3 | 刮削完整/部分/无记录/风控四类状态迁移符合主设计§6 |
| AC-4 | 榜单补未收录和已有缺资源影片，列表可查且版本正确 |
| AC-5 | 两款目标客户端播放永久ready资源，302后Range/seek通过 |
| AC-6 | 冷资源超过8秒得到准备状态，任务完成后手动重试播放指定真流；无进度污染 |
| AC-7 | 文件确实消失可回退；token/429/超时不清除资源绑定 |
| AC-8 | TTL清理保护活动会话和永久库，异步确认且重启仍能完成 |
| AC-9 | A/B进度隔离，同用户跨设备续播符合当前活动会话规则 |
| AC-10 | 115 token失效触发告警，本地浏览/配置仍可访问 |
| AC-11 | 当前旧库副本迁移、重复迁移、故障回滚、主键字段对比通过 |
| AC-12 | 同版本并发合并，不同版本独立；资源不属于影片时拒绝 |
| AC-13 | 远端接受转存、本地回填前崩溃；重启先对账，不盲目重发 |
| AC-14 | 删除影片、根重叠/移动、旧清理与新转存竞争，均不误删或遗忘资产 |
| AC-15 | 无写入且Janitor关闭时自然过期，选源查询仍正确 |
| AC-16 | 唯一变多版本、无字幕/破解/有码、同分和人工锁评分正确 |
| AC-17 | 正文番号和资源身份全部样例通过，冲突不静默合并 |
| AC-18 | 停机45天、双包半失败、同hash更新，水位和全量追补正确 |
| AC-19 | 扫描第二页失败、同数量文件移动、根部/嵌套/ISO处理正确 |
| AC-20 | 重复stopped不多计完播，旧会话迟到不覆盖新进度，未知时长不误判 |
| AC-21 | 普通用户不能管理；不能改他人进度；停用/过期票据/未授权WS被拒绝 |
| AC-22 | secret保留/替换/清除、环境覆盖、错误密钥、备份恢复和参数快照正确 |
| AC-23 | 指定压力下延迟、峰值内存、磁盘缓存与队列预算通过 |
| AC-24 | 榜单日程、授权/用户/视图入口、告警恢复、日志保留可操作 |

以上是必须执行的场景清单，不是已通过结果。G0记录外部能力可行性；P8记录正式服务全部AC的证据。
