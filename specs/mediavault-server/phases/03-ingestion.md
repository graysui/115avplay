## 验收与交付

1. 合法包与参考结果一致，损坏/越界/超预算包拒绝且不推进水位。
2. 重复包无重复资源；高优先字段受控更新，人工锁/运行资产不被覆盖。
3. 两个来源未全成功不推进全局水位；停机45天可追补或明确sync_gap。
4. 失败可重启恢复；非exempt新片进入auto，exempt不会被通用新片默认覆盖。
