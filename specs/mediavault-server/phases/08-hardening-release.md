- 单二进制（或 Docker 镜像）生产包
- 端到端验收报告（AC-1~AC-10 结果）
- 部署与运维文档

## 验收标准
1. `spec.md` §9 的 AC-1 ~ AC-10 全部通过；
2. `/readyz` 在依赖异常时返回非 200 并给出原因；
3. 制造 115 token 失效 / JavDB 风控场景，能触发告警且服务不崩溃；
4. 单二进制启动即用（含前端），无需额外文件（数据库除外）；
5. 空闲内存与查询/播放延迟满足 NFR-2 / NFR-3；
6. Janitor 白名单安全测试通过：尝试清理白名单外目录被拒绝。

## 风险 / 备注
- 端到端验收依赖真实 115 账号与可用磁力，需准备测试资源；
- 若某客户端兼容性问题无法在 P8 解决，记录为已知限制并在 README 标注。
